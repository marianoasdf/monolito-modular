# Rotisserie module

Este módulo debe seguir la misma estructura que barbería:

- `domain` para pedidos, menú y estados.
- `application` para casos de uso.
- `interface` para HTTP y UI adapters.
- `infra` para persistencia e integraciones.

Entidades candidatas:

- `RotisserieOrder`
- `RotisserieMenuItem`
- `RotisserieDeliveryArea`
